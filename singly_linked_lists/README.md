# C - Singly linked lists

This project introduces singly linked lists and their
manipulation in the C programming language.

## Learning Objectives

- Understand the difference between arrays and linked lists.
- Understand when and why to use linked lists.
- Learn how to build and traverse singly linked lists.
- Understand pointers and double pointers.
- Learn how to allocate and free memory dynamically.
- Add nodes at the beginning and end of a linked list.

## Files

| File | Description |
| --- | --- |
| lists.h | Structure definition and function prototypes |
| 0-print_list.c | Prints all elements of a linked list |
| 1-list_len.c | Returns the number of nodes |
| 2-add_node.c | Adds a node at the beginning |
| 3-add_node_end.c | Adds a node at the end |
| 4-free_list.c | Frees all nodes of a linked list |

## Requirements

- Ubuntu 20.04 LTS
- GCC compiler
- Betty coding style
- GNU89 standard
