# C - Pointers, Arrays and Strings

Functions for working with pointers, strings, and integer arrays.


Task 0 : Updates an integer to 98 through a pointer.
Task 1 : Swaps the values of two integers through pointers.
Task 2 : Returns a string's length, excluding the null terminator.
Task 3 : Prints a string followed by a new line.
Task 4 : Prints a string backwards followed by a new line.
Task 5 : Reverses a string in place.
Task 6 : Prints every other character, starting with the first.
Task 7 : Prints the second half of a string, skipping the middle character for odd lengths.
Task 8 : Prints integer array elements separated by a comma and a space.
Task 9 : Copies a string, including its null terminator, and returns the destination pointer.
Task 10 : Converts the first digit sequence to an integer, accounting for preceding signs.

Printing functions add a final new line.

# More Pointers, Arrays and Strings

These functions manipulate strings and integer arrays without calling
the standard library. Prototypes are declared in `main.h`.

Task 0 : Appends src to dest, adds a null terminator, and returns dest.
Task 1 : Appends at most n source characters, adds a null terminator, and returns dest.
Task 2 : Writes n bytes, copying src and padding with null bytes if needed; returns dest.
Task 3 : Compares strings using their first differing unsigned bytes.
Task 4 : Reverses n integers in place by swapping opposite elements.
Task 5 : Converts ASCII lowercase letters to uppercase in place.
Task 6 : Capitalizes words at the start and after the specified separators.
Task 7 : Replaces a/A, e/E, o/O, t/T, l/L with 4, 3, 0, 7, 1.
