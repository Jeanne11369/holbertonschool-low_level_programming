# C - Singly linked lists

This project introduces singly linked lists and their manipulation in C.

## Learning Objectives

- Understand the difference between arrays and linked lists.
- Understand how nodes are connected using pointers.
- Learn how to build and traverse linked lists.
- Learn how to allocate and free memory for linked lists.

## Files

| File | Description |
| --- | --- |
| lists.h | Header file containing the structure and function prototypes |
| 0-print_list.c | Prints all elements of a linked list |
