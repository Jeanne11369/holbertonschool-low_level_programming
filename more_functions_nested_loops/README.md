# Project C - More function, more nested loops

0-isupper.c - Checks whether a character is uppercase.
1-isdigit.c - Checks whether a character is a digit from 0 to 9.
2-mul.c - Multiplies two integers.
3-print_numbers.c - Prints the numbers from 0 to 9.
4-print_most_numbers.c - Prints the numbers from 0 to 9, except 2 and 4.
5-more_numbers.c - Prints the numbers from 0 to 14 ten times.
6-print_line.c - Draws a straight line using underscores.
7-print_diagonal.c - Draws a diagonal line using backslashes.
8-print_square.c - Prints a square using '#'.
9-fizz_buzz.c - Prints 1 to 100 with Fizz, Buzz, and FizzBuzz substitutions.
10-print_triangle.c - Prints a right-aligned triangle using '#'.
